# MOOC.fi Java Programming

My solutions for the Java Programming I and II courses by the University of
Helsinki (MOOC.fi), parts 1 to 14.

Programming I covers parts 1-7: variables, conditionals, loops, methods,
lists, arrays, strings and basic object-oriented programming.
Programming II covers parts 8-14: hash maps, inheritance and interfaces,
streams and file handling, exceptions and packages, generics and your own
data structures, and JavaFX applications.

Each folder is one exercise, using the original names from the course
(e.g. `part08-Part08_01.Cubes`). Built with Apache NetBeans and the TMC plugin.

Completed: October 2025

Course page: https://java-programming.mooc.fi
